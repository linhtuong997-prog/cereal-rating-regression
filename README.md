# cereal-rating-regression

Multiple linear regression for the rating of breakfast cereals (Section 5.5 of the Probability & Statistics assignment).

- Data: cereal.csv (80 Cereals, Kaggle): https://www.kaggle.com/datasets/crawford/80-cereals
- Code: section_5_5.R (R 4.x; packages: car, lmtest)
- How to run: put cereal.csv and section_5_5.R in the same folder, then run section_5_5.R in R or RStudio. Figures are saved to figures_5_5/.
